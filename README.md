# 🏁 MCST3RX Race Control

**Race Control. Your Way.**

A Windows companion application for NASCAR 25 and NASCAR 26, with distinct original trainer feature catalogs, customizable hotkeys and game-specific compatibility controls.

> **Release status:** v1.2.0 is a development target, not an accepted published release.  
> **Platform:** Windows x64  
> **Source code:** Private; not open source

---

## 📥 Download

Official approved builds are distributed through [GitHub Releases](https://github.com/mcst3rx/MCST3RX-Race-Control-Releases/releases). The latest published release, if available, is separate from the unreleased v1.2.0 target.

Verify any published SHA-256 checksum and use only official MCST3RX distribution channels. Never disable security software to run an unsigned executable.

---

## ✨ Features

- Original NASCAR 25 catalog: **19** historically gameplay-verified features
- Original NASCAR 26 catalog: **20** historically gameplay-verified features
- Game selection, connection/disconnection, custom hotkeys and live value editors
- Fuel, vehicle-condition, grip, lap and career features; game-specific physics actions

**Historical acceptance is for the original trainers, not proof that the rebuilt v1.2.0 executable works in gameplay.**

## 🛡️ Safety and limitations

Intended for offline gameplay. Back up important saves. Disconnect/Restore before switching games. Native compatibility, ownership, cleanup and lifecycle must be verified on supported builds; do not present historical trainer tests as rebuilt-executable acceptance.

---

## 🚀 Installing and getting started

Download only a published Windows ZIP, extract the full folder including runtime DLLs, then run the executable. Launch the supported game, select it in Race Control, connect, use only supported features, and Disconnect/Restore before exiting.
